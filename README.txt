- lib/models/workout.dart
- lib/models/daily_log.dart
- lib/models/goal.dart
- lib/screens/workout_screen.dart
- lib/screens/widgets/workout_summary.dart
- lib/screens/widgets/workout_list.dart
- lib/screens/widgets/add_workout_dialog.dart

LƯU Ý:
1. Đây là bộ file mã nguồn để đưa vào dự án Flutter Healthmate có sẵn, không phải toàn bộ dự án Flutter.
2. Giải nén ZIP, sau đó sao chép thư mục lib vào thư mục gốc dự án Healthmate.
3. Nếu dự án đã có file trùng tên, hãy sao lưu và so sánh trước khi ghi đè.
4. Màn hình hiện dùng dữ liệu mẫu trong bộ nhớ; dữ liệu thêm/xóa sẽ không được lưu sau khi tắt ứng dụng.
5. Chưa kết nối API/database. Cần kiểm tra tên trường JSON với backend của nhóm trước khi tích hợp.
6. Sau khi sao chép, chạy: flutter analyze
